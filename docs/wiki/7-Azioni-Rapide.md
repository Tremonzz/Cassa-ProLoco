# 7. Azioni Rapide & Scorciatoie da Tastiera

Di seguito la tabella con tutte le combinazioni di tasti e scorciatoie per operare alla massima velocità durante la sagra:

| Tasto / Scorciatoia | Azione | Dove si usa |
|:---|:---|:---|
| `Esc` | Svuota Carrello | Schermata Cassa |
| `Esc` | Chiudi Finestra Pop-Up | Tutte le schermate |
| `F1` | Apre lo Storico Ordini | Schermata Cassa |
| `F2` | Apre le Statistiche Rapide | Schermata Cassa |
| `F3` | Apre la Schermata di Gestione Menu | Schermata Cassa |
| `Ctrl + Invio` | Inserisce un Nuovo Prodotto | Schermata Gestione Menu |
| `Ctrl + Invio` | Stampa Ordine | Schermata Cassa |
